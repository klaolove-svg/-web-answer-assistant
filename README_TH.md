# Web Answer Assistant – Ready to Use

เว็บแอปสำหรับเลือกข้อความโจทย์จากเว็บไซต์แล้วส่งให้ AI วิเคราะห์ โดยไม่ต้องติดตั้งโปรแกรมหรือ Extension บนเครื่องผู้ใช้

## สิ่งที่ต้องมีเพื่อเปิดใช้เป็นเว็บจริง
1. บัญชีผู้ให้บริการโฮสต์เว็บที่รองรับ Python (ตัวอย่างคู่มือนี้ใช้ Render)
2. บัญชี OpenAI API และ API Key ที่มีสิทธิ์เรียก API
3. นำโฟลเดอร์นี้ขึ้น GitHub repository

> หมายเหตุ: ไฟล์ Source Code ไม่สามารถกลายเป็น URL สาธารณะที่ออนไลน์ได้เอง ต้อง Deploy ไปยังบริการโฮสต์ก่อน ผู้ใช้ปลายทางไม่ต้องติดตั้งอะไร แต่เจ้าของระบบต้องตั้งค่าโฮสต์และ API Key หนึ่งครั้ง

## Deploy บน Render
1. สร้าง GitHub repository ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. เข้า Render Dashboard แล้วเลือก New > Blueprint
3. เชื่อมต่อ GitHub และเลือก repository ที่อัปโหลด
4. Render จะอ่าน `render.yaml` และสร้าง Web Service
5. ในหน้า Environment ของบริการ ใส่ค่า `OPENAI_API_KEY` เป็น API Key ของผู้ดูแลระบบ
6. รอ Deploy เสร็จ แล้วเปิด URL ที่ Render แสดง เช่น `https://ชื่อบริการ.onrender.com`
7. เปิด URL ตรวจสอบว่าเว็บแสดงผลได้

## ตั้งค่าปุ่ม One-Click
1. เปิด `bookmarklet.txt`
2. แทนที่ `https://YOUR-DEPLOYED-DOMAIN/` ด้วย URL จริงของเว็บที่ Deploy แล้ว
3. คัดลอกโค้ดทั้งบรรทัด
4. ใน Chrome/Edge กด Ctrl+Shift+B เพื่อแสดงแถบบุ๊กมาร์ก
5. เพิ่ม Bookmark ใหม่ ชื่อ `One-Click Answer` แล้ววางโค้ดในช่อง URL

## วิธีใช้งาน
1. เปิดเว็บไซต์ที่มีข้อความคำถาม
2. ลากเมาส์เลือกโจทย์พร้อมตัวเลือก
3. คลิก Bookmark `One-Click Answer`
4. หน้าต่าง Web Answer Assistant จะเปิดขึ้นพร้อมข้อความที่เลือก
5. คลิก `วิเคราะห์คำตอบ` แล้วอ่านคำตอบและเหตุผล
6. ใช้ปุ่มคัดลอกคำตอบได้

## ความเป็นส่วนตัวและข้อจำกัด
- ข้อความที่เลือกจะถูกส่งไปยัง Web App และ OpenAI API เพื่อประมวลผล
- API Key เก็บใน Environment Variable บนเซิร์ฟเวอร์ ไม่ฝังในหน้าเว็บ
- Bookmarklet ทำงานได้เฉพาะเมื่อเว็บไซต์ไม่ปิดกั้นการทำงานลักษณะนี้ และเบราว์เซอร์อนุญาตให้เปิด popup
- ไม่มี Extension แต่ต้องคลิก Bookmarklet หลังเลือกข้อความ เพราะหน้าเว็บหนึ่งไม่สามารถอ่าน selection จากอีกเว็บไซต์ได้เอง
- ผลลัพธ์ AI อาจผิดพลาด ควรตรวจสอบคำอธิบายและแหล่งข้อมูล
- หากใช้แผนโฮสต์ฟรี อาจมีการพักระบบเมื่อไม่มีการใช้งาน ทำให้การเปิดครั้งแรกช้าลง และมีข้อจำกัดตามผู้ให้บริการ
